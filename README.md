# Customer Segmentation with K-Means Clustering

This project applies unsupervised machine learning to segment mall customers based on their income and spending behavior. Using the K-Means clustering algorithm, the analysis identifies distinct customer groups that can help businesses better understand shopping patterns and develop targeted marketing strategies. The project includes data preprocessing, feature scaling, cluster evaluation, visualization, and demographic analysis.

# Features
- Cleaned and prepared customer data by converting income values to numeric format and removing unnecessary identifiers.
- Standardized features using Z-score normalization with StandardScaler.
- Determined the optimal number of clusters using the Elbow Method.
- Built a K-Means clustering model with five customer segments.
- Visualized customer clusters and centroid locations with Matplotlib.
- Performed demographic analysis by calculating average age and gender distribution for each cluster.
- Summarized business insights and recommendations for customer segmentation and targeted marketing strategies.
